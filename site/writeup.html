Write-up

Question

Robustness benchmarks check that a model's output survives rotation, cropping, colour jitter, and JPEG compression. This audit checks whether the internal features survive too, on one model (CLIP ViT-B/32), one SAE, and 2000 ImageNet validation images.

Method

For each transform at 8 strengths, output stability is the cosine similarity of image embeddings and feature stability is the Jaccard index of top-32 SAE feature sets, both against strength 0. RII is the mean gap over strengths above 0, with bootstrap CIs over images. Four nulls (random subset, shuffled pairing, k-sensitivity, threshold noise) ship with every number.

Results

See the Curves view for the four RII values. Report effect sizes, not just significance; state negative results plainly.

Nulls

Null D (threshold noise) is the critical control: if the gap vanishes when only features above twice the threshold count, the finding is threshold flicker, not representational instability — and is reported as such.

Limitations

One model, one SAE, one dataset. No claim about vision transformers in general. Features are never described as meaningful without top-activating patch contact sheets. No mitigation is proposed.
